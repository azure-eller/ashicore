## User problem

Production needs a repeatable recipe so manufacturing orders can calculate material requirements.

## Steps

1. Create the material items.
2. Create the product item.
3. Open the product recipe.
4. Add each material and quantity needed for the product unit or batch basis used by your team.
5. Review units and expected yield.
6. Save and create a test manufacturing order.

## System behavior

Manufacturing orders use recipe data to calculate expected material demand. Recipe changes should be intentional because open or future production work depends on them.

## Edge cases

If substitutes, scrap, yield loss, or alternate units matter, document the operating rule before encoding it in the recipe. Do not use vague material names or mixed units to hide uncertainty.
