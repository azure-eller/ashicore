## Setup order

1. Confirm organization details.
2. Invite the core operating team.
3. Create item master data.
4. Enter opening stock or run a stocktake.
5. Add suppliers and customers.
6. Configure accounting only after operational records are clean enough to sync.

## Permissions

Give users the access needed for their work. Limit administrative access to people responsible for account setup, team management, integrations, and sensitive workflows.

## Operational readiness

Before relying on Ashicore for daily work, verify one inventory flow, one purchasing flow, one manufacturing flow if applicable, and one sales/shipping flow.
