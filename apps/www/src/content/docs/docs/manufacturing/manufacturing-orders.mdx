Manufacturing orders plan and execute production for one product. The stored status is open or done; the UI derives the production state from start, block, output, and completion history.

<p class="po-meta">
  <span class="po-chip"><b>4</b> production states</span>
  <span class="po-chip">recipe snapshot</span>
  <span class="po-chip">lot-backed output</span>
</p>

## Production states

| State | What it means | Edit plan | Produce | Delete |
| --- | --- | --- | --- | --- |
| Not started | The order is open and no work has started. | yes | yes | yes |
| Work in progress | Production has started. | limited | yes | limited |
| Blocked | The order is open but cannot proceed. | limited | no | limited |
| Done | Output is recorded and the order is closed; it can return to Work in progress while its produced stock remains available. | no | no | no |

## Print production documents

Open a saved order's header menu to print the full manufacturing order, an
order without costs, an operator notes sheet, or a pick list. Once production
has started, the menu also offers a partial-progress order. **Print** opens the
complete server-rendered PDF in a new tab, while **Download manufacturing order
PDF** saves the full order. From the orders list, select up to 50 orders to print
or download the full orders together as one PDF. Pick lists include remaining
ingredient quantities and planned source lots, including any unassigned shortage.
