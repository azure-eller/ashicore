Resources are the labor, machine, overhead, or other cost centers that product operations can reference. Manufacturing orders snapshot operation cost context so historical orders keep their cost trail.

## Manage Resources

Open **Manufacturing > Resources** to see the active resource list. The grid shows name, type, loaded rate per hour, and description. Use **New Resource** to add a cost center, or **Edit** on a row to update it.

## The Resource Form

The dialog has four fields. **Name** and **Loaded rate / hour** are required. The loaded rate must be zero or positive.

<Aside type="note" title="Loaded means fully burdened">
Recipe operation costs multiply the loaded hourly rate by crew size and planned minutes. The result is snapshotted onto manufacturing orders when the order copies the current product recipe.
</Aside>

## Fields

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| Name | text | none | User-facing resource name. Required. |
| Type | enum | `labor` | `labor`, `machine`, `overhead`, or `other`. |
| Loaded rate / hour | money | none | Fully burdened hourly cost. Must be zero or positive. |
| Description | text | blank | Optional operating context. |
| Deleted at | timestamp | blank | Set when the resource is archived. |

## Archiving

Deleting a resource archives it for future selection and detaches active BOM operation references. Manufacturing order snapshots keep their copied operation costs for history.

<Aside type="caution" title="Archiving changes live recipes">
The delete action removes BOM operation cost lines that still reference the resource. Existing manufacturing orders keep their copied operation cost details, with the resource link detached.
</Aside>
