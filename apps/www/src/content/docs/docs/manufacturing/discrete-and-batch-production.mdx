Ashicore supports two manufacturing modes. The mode comes from the product recipe at order creation and is snapshotted onto the manufacturing order.

<p class="po-meta">
  <span class="po-chip">discrete: quantity</span>
  <span class="po-chip">batch: whole batches</span>
  <span class="po-chip">recipe snapshot</span>
</p>

## Discrete: Make A Quantity

Discrete production is one production run that creates finished output for a requested quantity. The order field is **Quantity**, and ingredient totals scale by output quantity.

  </div>
</Frame>

## Batch: Make N Batches With Planned Output

Batch production creates batch rows with their own status and output lot. The order fields are **Number of batches** and **Expected output**. Ingredient demand scales from the batch count; finished-good expected supply uses the order's planned output. Batch production is included on both Free and Pro.

## How Ingredient Quantities Scale

| Recipe basis | Order input | Ingredient total |
| --- | --- | --- |
| Unit | Quantity | `quantity per unit × output quantity` |
| Batch | Number of batches | `quantity per batch × batch count` |

<Aside type="caution" title="Batch counts must be whole">
Batch orders always use a whole number of batches. You can edit expected output separately when the planned yield differs from the recipe's default batch yield.
</Aside>
