# Slow Test Stories

Only these slow spec files are allowed. Slow specs are operating stories, not
bug archives: each file must describe a workflow a small manufacturer would
recognize and must avoid incidental UI/regression breadth.

| File | Lane | Active tests | Story | Must prove | Not covered | Safety | Justification |
| --- | --- | ---: | --- | --- | --- | --- | --- |
| `sales-fulfillment.spec.ts` | `sales` | 7 | A customer places an order, demand appears, activities are tagged to a project and filtered by chip, a follow-up task is logged and worked off the due queue, stock ships partially/finally, pricing suggestions resolve, and order/inventory state stays correct. | customer context snapshot, project-tagged activity + chip/pill stream filtering, task create + due-queue surfacing + completion (`done` + `completedAt`), demand creation, partial/final shipment, order status, stock consumed once, delete releases demand, pricing scope precedence, quantity break boundaries, manual price override preservation | CRM breadth, full pricing matrix, card/action UI, delete guard matrix | `serial-only` | |
| `purchasing-receiving.spec.ts` | `purchasing` | 8 | A buyer submits a PO, sends supplier documents, receives it in parts, expected supply becomes physical stock, and later corrects freight: eligible available tracked stock revalues landed cost via append-only events, while consumed and untracked-v1 stock do not block the PO edit. | supplier/PO setup, ordered expected supply, sent supplier-copy state in the email sheet, partial/final receipt, lot/balance truth, freight-edit landed-cost revaluation (eligible lot + material cost rebased, receipt untouched), freight save after consumption with remaining available revaluation, untracked v1 freight save without revaluation | all supplier fields, validation variants, delete guards, untracked MAC revaluation (phase 2) | `serial-only` | |

| `stocktake-workflow.spec.ts` | `stocktake` | 11 | An operator creates a stocktake, saves/reloads sparse counts, must supply a reason to commit, sees reconciled state carrying that reason, and records an unexpected found lot that becomes new lot stock with a posted gain.
