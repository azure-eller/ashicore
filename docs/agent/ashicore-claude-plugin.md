# Ashicore Claude Plugin

Download:

```txt
https://ashicore.app/downloads/ashicore-claude-plugin.zip
```

The plugin contains:

- Ashicore MCP reference: `https://ashicore.app/api/agent/mcp`
- One skill: production schedule

The skill tells Claude to:

- call Ashicore production planning data
- format what to make each day as a schedule
- call out shipment misses
- say what must happen on what day to avoid each miss
